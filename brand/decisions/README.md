# Decisions (ADR)

Este diretório registra decisões arquiteturais já tomadas para o
LinkedIn Content Engine, especificamente na camada visual.

Cada ADR é curto, imutável após aprovado, e serve como referência
para evitar retrabalho ou reinterpretação em prompts futuros.

Formato do nome:
ADR-XXX-titulo-curto.md

Status possíveis:
- proposto
- aprovado
- substituído (indicar por qual ADR)
