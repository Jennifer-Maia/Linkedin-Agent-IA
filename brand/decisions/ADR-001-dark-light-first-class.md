# ADR-001: Dark e Light como direções de primeira classe

## Status
Aprovado — 2026-09-14

## Contexto
A identidade visual inicial tinha o dark como base dominante.
Havia risco de tratar o light como modo secundário ou apenas
para uso interno.

## Decisão
Dark e Light são direções oficiais e equivalentes. Nenhuma das
duas é secundária. A escolha entre elas depende do conteúdo,
formato e histórico visual recente, não de hierarquia fixa.

## Consequências
- O sistema deve justificar a escolha de dark ou light por conteúdo.
- Nenhum prompt futuro deve reintroduzir "light apenas para uso interno".
- O banner dark permanece como âncora de marca (ver ADR-002),
  mas isso não implica dominância sobre outras peças.
